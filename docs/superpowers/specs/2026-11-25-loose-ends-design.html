Loose ends: the last untrue lines after closing

Makes the developer documents name the simulation as it now is, drops a link that leads nowhere, keeps the focused skip link off the header's targets, and clears the words that still name Remix.

Purpose

This unit runs after closing, on the integration branch with every other unit of the design merged. It produces no interface row and needs none. It carries P5 and call 6 (one address), P11 (the brush does not come back), P13 (no Remix) and the WCAG 2.2 AA global constraint.

Interfaces

Produced: none. Needed: none. The unit changes words, one link, one class list and test fixtures.

Global constraints

  • One future: the same policy document always gives the same forecast. No game state reaches the worker except through the policy document.
  • No file the dataset version hashes is changed: pipeline, src/lib/config.ts, src/lib/{data,generator,timelapse}, src/lib/plan/{geometry,types}.ts, src/lib/sim/finance (pipeline/lib/version.ts:41). The dataset version stays as it is.
  • A policy node acts on a lever the code already has, at a value the code already sources. No node invents a value.
  • The painted area, own pools, the City funding scale and market terms are never offered in a game.
  • Published plans and policies open and play in full, as today.
  • WCAG 2.2 AA: everything works from the keyboard; targets are at least 24 px; motion follows the reduced-motion setting; nothing flashes more than three times a second.
  • Page text is short. A node is a name, a line and a price.
  • The CSP is not widened. Sound is made in the browser; no audio file, font or script is added.
  • A runtime dependency is not added without a credit in src/lib/attribution.ts. None is expected.
  • Code style: 2-space indent, single quotes, no trailing commas, 100 columns.
  • Vitest runs with expect.requireAssertions. Tests are colocated.
  • A schema change goes through npm run db:generate. Migrations are never edited by hand.
  • Signoff fails on server stderr, on timing crutches and on retried flakes. Timing is measured only on a quiet machine.
  • Port 4173 belongs to whichever session started the preview. Never kill it; wait.
  • Commits use Conventional Commits and carry no Claude attribution.
  • Work happens in git worktrees under .claude/worktrees/.

Design

The documents

  • In docs/dev/{sim-page,timeline-ui,map-interfaces,map-stream,world-score,world-funding}.md, "/sim" as the name of the page becomes "the simulation", and "/sim" as an address becomes /. Each sentence is made true of the code as it is.
  • docs/dev/sim-page.md's title becomes "The simulation page"; docs/dev/timeline-ui.md's becomes "The simulation's timeline".
  • docs/dev/sim-page.md:86 quotes plan-sharing.md's heading as it now reads, "Policies (the simulation)".
  • "/sim" stays where a sentence says that /sim redirects to /, in a test name or path, and in a dated measurement row.

The simulation with no scenario

  • The message "The simulation isn't available for dataset {version}. It needs data this dataset doesn't have." keeps its words, its role and fzp-status, and carries no action. The brush is the opening only (P11), and / is this page.
  • The message stays a card (data-shape="card"), as today.
  • e2e/fzp.spec.ts and e2e/sim-activity.spec.ts assert the message has no link, where they asserted "Go to the editor".

The skip link

  • The focused skip link covers no other target. It is in flow before the header while focused (sr-only focus:not-sr-only, no focus:absolute), so the header moves down by its height while it has focus and returns when focus leaves.
  • It keeps its words, its target #main, its look (focus:bg-white focus:px-3 focus:py-2) and its place as the first Tab stop.
  • e2e/game-a11y.spec.ts adds one case: on the tree and in the opening, at 375 and 1280 px, with the skip link focused, expectNoA11yViolations(page) passes.

Words that name Remix

  • The comment at src/lib/sim-page/sim-doc.ts:2 says what the file holds now: the simulation's schema 3 policy document, which stored rows and old autosaves still hold. It names neither /sim nor Remix.
  • PaintTab.svelte.spec.ts uses the intro "Read-only.", MSG.readOnly.
  • NoticeStack.svelte.spec.ts uses a notice id saved with the words "Saved" and "Saved toast"; autosave.svelte.spec.ts uses the title "Handed off". The behaviour each test checks is unchanged.
  • Not changed: src/lib/config.ts (APP_NAME, a hashed file, unused); the shared pages' DatasetNotice value 'remix' (the name of the older-data notice N5 in src/lib/server/sharing/shared-page.ts, SharedBanner.svelte, sim-session.ts and their tests); tests that assert Remix is gone; and the 404 for /favicon.ico, since the site has never had a favicon and the package adds none.

Decisions

  • The skip link goes in flow rather than to another absolute place. Any absolute place on the map pages covers a header or notice target; in flow it covers none.
  • The no-scenario message loses its link rather than gaining another. No page offers the brush after the opening, and About is in the header.
  • The 'remix' notice value keeps its name. It is an internal value of the shared pages' server side, which the package does not change, and no reader sees it.
