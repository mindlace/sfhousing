Game core: units, limits, the ladder, side goals and the saved game

The pure rules of the incremental loop: the game's state and its parser, units by kind, limits from what is bought, the ladder of deadlines, a run's result and settling, side goals, and every word the game shows.

Purpose

This subsystem holds the rules of the game as plain functions. It has no Svelte, no storage and no worker. Every other unit of the loop reads these rules: the store saves the state they define, the page asks them what runs and what a run paid, and the screens show their words.

  • P9 every completed home counts to the goal; only collected homes become units. readRun reads homes from the forecast; settle credits only collected.
  • P10 units are amounts by kind, with one kind, home. Every function on units iterates UNIT_KINDS, so a second kind is a change to that list.
  • P11 a painted area runs only in the open game.
  • P12 switching a lever off is the document's own on; nothing here refunds.
  • P15 only v: 2 saves are read.
  • D4 own pools, the City funding scale and market terms run only in the open game.
  • R5 taking the next rung is the player's choice: takeNext is a separate step from settle.
  • Composer calls 2, 4, 5, 8, 9, 10, 11, 16 and 17 are carried by limitsOf, within, ladder, settle and SIDE_GOALS.

Units (units.ts)

// src/lib/game/units.ts
import { UNIT_KINDS, type UnitKind, type Units } from './state';

const amount = (u: Units, k: UnitKind): number => u[k] ?? 0;
const has = (u: Units, k: UnitKind): boolean => u[k] !== undefined;

export function credit(a: Units, b: Units): Units {
  const out: Units = {};
  for (const k of UNIT_KINDS) if (has(a, k) || has(b, k)) out[k] = amount(a, k) + amount(b, k);
  return out;
}

export function affords(have: Units, price: Units): boolean {
  return UNIT_KINDS.every((k) => amount(have, k) >= amount(price, k));
}

export function spend(have: Units, price: Units): Units {
  if (!affords(have, price)) throw new RangeError('Not enough units');
  const out: Units = {};
  for (const k of UNIT_KINDS) {
    if (has(have, k) || has(price, k)) out[k] = amount(have, k) - amount(price, k);
  }
  return out;
}

export function shortBy(have: Units, price: Units): Units {
  const out: Units = {};
  for (const k of UNIT_KINDS) {
    const d = amount(price, k) - amount(have, k);
    if (d > 0) out[k] = d;
  }
  return out;
}

export function total(u: Units): number {
  let t = 0;
  for (const k of UNIT_KINDS) t += amount(u, k);
  return t;
}
  • Every function walks UNIT_KINDS, never Object.keys: a key that is not a kind is ignored, and a second kind (P10) needs only the list to change.
  • A result holds a kind exactly when either input held it. shortBy holds only the kinds short, so {} means affordable.
  • total is what the header shows while there is one kind.

type Plain = Record<string, unknown>;
const isPlain = (x: unknown): x is Plain =>
  typeof x === 'object' && x !== null && !Array.isArray(x);
const isTime = (x: unknown): x is string =>
  typeof x === 'string' && Number.isFinite(Date.parse(x));
const isWhole = (x: unknown, min: number): x is number =>
  typeof x === 'number' && Number.isSafeInteger(x) && x >= min;
const isText = (x: unknown): x is string => typeof x === 'string' && x !== '';
const isNum = (x: unknown): x is number => typeof x === 'number' && Number.isFinite(x);

const OPEN_STAGES = [
  'preApplication',
  'filed',
  'entitled',
  'permitFiled',
  'permitIssued',
  'construction'

/** Every value a whole number of 0 or more; only UNIT_KINDS kept. */
function parseUnits(x: unknown): Units | null {
  if (!isPlain(x)) return null;
  for (const v of Object.values(x)) if (!isWhole(v, 0)) return null;
  const out: Units = {};
  for (const k of UNIT_KINDS) if (Object.hasOwn(x, k)) out[k] = x[k] as number;
  return out;
}

function parseMet(x: unknown): MetRung | null {
  if (!isPlain(x)) return null;
  const { rung, reachedOn, datasetVersion, at } = x;
  if (!isWhole(rung, 0) || !isWhole(reachedOn, 0)) return null;
  if (!isText(datasetVersion) || !isTime(at)) return null;
  return { rung, reachedOn, datasetVersion, at };
}

export function parseRunResult(x: unknown): RunResult | null {
  if (!isPlain(x)) return null;
  const { rung, amount, datasetVersion, at, homes, reachedOn, waitingMoney } = x;
  if (!isWhole(rung, 0) || !isWhole(amount, 1)) return null;
  if (!isText(datasetVersion) || !isTime(at)) return null;
  if (!isNum(homes)) return null;
  if (reachedOn !== null && !isWhole(reachedOn, 0)) return null;
  if (waitingMoney !== null && !isNum(waitingMoney)) return null;
  if (!isPlain(x.stages)) return null;
  const stages = {} as RunResult['stages'];
  for (const s of OPEN_STAGES) {
    const v = x.stages[s];
    if (!isNum(v)) return null;
    stages[s] = v;
  }
  const dropped = parseUnits(x.dropped);
  const collected = parseUnits(x.collected);
  if (!dropped || !collected) return null;
  let lump: Units | null = null;
  if (x.lump !== null) {
    lump = parseUnits(x.lump);
    if (!lump) return null;
  }
  if (!Array.isArray(x.side)) return null;
  const side: RunResult['side'] = [];
  for (const e of x.side) {
    if (!isPlain(e) || !isText(e.id)) return null;
    const reward = parseUnits(e.reward);
    if (!reward) return null;
    side.push({ id: e.id, reward });
  }
  return {
    rung, amount, datasetVersion, at, homes, reachedOn, stages, waitingMoney,
    dropped, collected, lump, side
  };
}

export function parseGameState(
  x: unknown,
  nodes: readonly TreeNode[] = NODES,
  goals: readonly SideGoal[] = SIDE_GOALS
): GameState | null {
  // 1. A plain object at version 2 (P15).
  if (!isPlain(x) || x.v !== 2) return null;
  const { phase, firstWinAt, rung, runs } = x;
  // 2. The phase.
  if (phase !== 'opening' && phase !== 'runs') return null;
  // 3. The first win: null or a time.
  if (firstWinAt !== null && !isTime(firstWinAt)) return null;
  // 4. Bought: a plain object of whole numbers of 1 or more.
  if (!isPlain(x.bought)) return null;
  for (const v of Object.values(x.bought)) if (!isWhole(v, 1)) return null;
  // 5. Units.
  const units = parseUnits(x.units);
  if (!units) return null;
  // 6. The rung in play.
  if (!isWhole(rung, 0)) return null;
  // 7. Met rungs: each valid, strictly ascending by rung.
  if (!Array.isArray(x.met)) return null;
  const met: MetRung[] = [];
  for (const e of x.met) {
    const m = parseMet(e);
    if (!m || (met.length > 0 && m.rung <= met[met.length - 1].rung)) return null;
    met.push(m);
  }
  // 8. Side goals met: a plain object of times.
  if (!isPlain(x.side)) return null;
  for (const v of Object.values(x.side)) if (!isTime(v)) return null;
  // 9. Runs.
  if (!isWhole(runs, 0)) return null;
  // 10. The last result: null or a valid result.
  let last: RunResult | null = null;
  if (x.last !== null) {
    last = parseRunResult(x.last);
    if (!last) return null;
  }
  // 11. The phase agrees with the rest.
  if (phase === 'runs' && firstWinAt === null) return null;
  if (phase === 'opening' && (runs !== 0 || rung !== 0 || met.length > 0 || last !== null)) {
    return null;
  }
  // 12. Catalogue drift: drop unknown nodes, lower levels to the node's last.
  const byId = new Map(nodes.map((n) => [n.id, n]));
  const bought: Record<NodeId, number> = {};
  for (const [id, level] of Object.entries(x.bought as Record<string, number>)) {
    const node = byId.get(id);
    if (node && node.levels.length > 0) bought[id] = Math.min(level, node.levels.length);
  }
  // 13. Side goal drift: drop ids SIDE_GOALS does not have.
  const known = new Set(goals.map((g) => g.id));
  const side: Record<string, string> = {};
  for (const [id, at] of Object.entries(x.side as Record<string, string>)) {
    if (known.has(id)) side[id] = at;
  }
  // 14. Ladder drift: lower the rung to the last; drop met rungs past it.
  return {
    v: 2,
    phase,
    firstWinAt,
    bought,
    units,
    rung: Math.min(rung, RUNGS - 1),
    met: met.filter((m) => m.rung < RUNGS),
    side,
    runs,
    last
  };
}

export function parseGameSave(json: unknown): GameSave | null {
  if (!isPlain(json) || json.v !== 2) return null;
  const { id, name, nameIsDefault, savedAt, plan, policy } = json;
  if (typeof id !== 'string' || !isValidId(id)) return null;
  if (typeof name !== 'string' || name !== name.trim()) return null;
  const length = Array.from(name).length;
  if (length < 1 || length > SAVE_NAME_MAX) return null;
  if (typeof nameIsDefault !== 'boolean') return null;
  if (!isTime(savedAt)) return null;
  if (plan !== null && typeof plan !== 'string') return null;
  if (policy !== null && typeof policy !== 'string') return null;
  const state = parseGameState(json.state);
  if (!state) return null;
  return { v: 2, id, name, nameIsDefault, state, plan, policy, savedAt };
}
  • A field that is missing fails its check: undefined is neither null nor the type asked for.
  • Malformed data returns null for the whole save, as today. Only drift is repaired: a node, a side goal or a rung the current build no longer has (steps 12 to 14).
  • The result is rebuilt from the known fields, so an unknown field at any level is dropped.
  • units keeps a kind present with 0. A key that is not a kind must still be a whole number, and is then dropped.
  • side entries of a RunResult keep their ids even when SIDE_GOALS no longer has them: the result is a record of what was paid.
  • plan and policy are checked as null or text only.
  • save-shape.ts imports SAVE_NAME_MAX from saves.ts, which game-save keeps.

export function limitsOf(s: GameState, nodes: readonly TreeNode[] = NODES): Limits {
  const presets = new Set<string>();
  const measures = new Set<string>();
  const stops = new Set<StopType>();
  let bands = 0;
  let stories = 0;
  let reachM = 0;
  let { radiusPx, lingerMs, auto } = BASE_HANDS;
  for (const node of nodes) {
    const level = Math.min(s.bought[node.id] ?? 0, node.levels.length);
    for (let i = 0; i < level; i++) {
      const g = node.levels[i].grant;
      if (g.tag === 'preset') presets.add(g.preset);
      else if (g.tag === 'measure') measures.add(g.preset);
      else if (g.tag === 'stop') stops.add(g.stop);
      else if (g.tag === 'bands') bands = Math.max(bands, g.max);
      else if (g.tag === 'stories') stories = Math.max(stories, g.max);
      else if (g.tag === 'reach') reachM = Math.max(reachM, g.maxM);
      else if (g.what === 'radius') radiusPx = Math.max(radiusPx, g.value);
      else if (g.what === 'linger') lingerMs = Math.max(lingerMs, g.value);
      else auto = true;
    }
  }
  const done = finished(s);
  if (done) {
    for (const t of STOP_TYPES) stops.add(t);
    presets.add('observed');
  }
  const transit = done
    ? { bands: MAX_BANDS, stories: STORIES_MAX, reachM: BAND_MAX_M }
    : stops.size === 0
      ? { bands: 0, stories: 0, reachM: 0 }
      : {
          bands: Math.min(MAX_BANDS, Math.max(START_BANDS, bands)),
          stories: Math.min(STORIES_MAX, Math.max(START_STORIES, stories)),
          reachM: Math.min(BAND_MAX_M, Math.max(START_REACH_M, reachM))
        };
  return {
    open: false,
    presets,
    measures,
    stops,
    ...transit,
    custom: done,
    hands: { radiusPx, lingerMs, auto }
  };
}

const TAGS: Record<PolicyKind, readonly Policy['where']['tag'][]> = {
  zoning: ['transit', 'painted', 'category'],
  permitting: ['routes'],
  money: ['baseline', 'fund', 'terms']
};

export function within(kind: PolicyKind, p: Policy, l: Limits): boolean {
  if (l.open) return true;
  if (!TAGS[kind].includes(p.where.tag)) return false;
  switch (p.where.tag) {
    case 'painted':
      return false;
    case 'category':
      return l.stops.size > 0;
    case 'transit':
      return (
        l.stops.size > 0 &&
        p.where.stopTypes.every((t) => l.stops.has(t)) &&
        p.spans.every(
          (s) =>
            s.what.tag !== 'bands' ||
            (s.what.bands.length <= l.bands &&
              s.what.bands.every((b) => b.stories <= l.stories && b.maxM <= l.reachM))
        )
      );
    case 'routes':
      return (
        p.preset !== null &&
        l.presets.has(p.preset) &&
        (l.custom ||
          p.spans.every(
            (s) =>
              s.what.tag !== 'timing' ||
              (s.what.set.edits.length === 0 && s.what.set.routeShares === null)
          ))
      );
    case 'baseline':
    case 'fund':
    case 'terms':
      return (
        isGiven(p) &&
        (l.measures.has(p.preset as string) ||
          (FREE_MEASURES.includes(p.preset as string) && l.measures.size > 0))
      );
  }
}

const KINDS: readonly PolicyKind[] = ['zoning', 'permitting', 'money'];

export function runnable(doc: SimPolicy4, l: Limits): SimPolicy4 {
  if (l.open) return doc;
  const kinds = { ...doc.kinds };
  let changed = false;
  for (const kind of KINDS) {
    const list = doc.kinds[kind];
    const kept = list.filter((p) => within(kind, p, l));
    if (kept.length !== list.length) {
      kinds[kind] = kept;
      changed = true;
    }
  }
  return changed ? { ...doc, kinds } : doc;
}

/** A money policy made from a funding preset: its `preset` is the preset's id. */
export function isGiven(p: Policy): boolean {
  return (
    typeof p.preset === 'string' &&
    (p.where.tag === 'fund' || p.where.tag === 'baseline' || p.where.tag === 'terms')
  );
}
START_BANDS, START_STORIES, START_REACH_M
One band, 4 stories, 402 m: the limits from the first stop type until a bands, stories or reach grant raises them. 4 is the lowest band of the editor's default rule and 402 m the editor's band step and the default rule's inner distance. G5's first rule is one band at these.
FUNDING_PRESET_IDS
Every funding preset id the code writes, available or not. It fills OPEN_LIMITS.measures.
  • A level bought past a node's last level counts as the last; a node the catalogue does not have counts as nothing.
  • The largest bands, stories and reach grant wins, never below the starting limits and never above the editor's bounds (3 bands, 80 stories, 3219 m).
  • While no stop type is bought, bands, stories and reachM are 0, whatever else is bought.
  • Once the last rung is met (finished), stories is 80, bands 3, reachM 3219, every stop type is in, custom is true, and observed joins presets, so that "Custom timing" (a permitting policy whose preset is observed) runs.
  • presets and measures are never widened by the ending: what was bought runs.
  • hands starts at BASE_HANDS; the largest radius and linger win; any auto grant makes auto true.
  • within ignores on: an off policy outside the limits is dropped as well, and an off one inside them stays off.
  • within returns false for a selector that does not belong to kind (parse4.ts:26-30), except in the open game.
  • A transit rule is within only once a stop type is bought, even when its list of stop types is empty.
  • A permitting policy with no custom edit and no custom shares in any span is within when its preset is bought. A preset's own timers and shares are never custom.
  • Market terms (terms), an own pool and the City funding scale have no preset, so they are never given and never within outside the open game (D4).
  • runnable keeps list order and returns the same document object when it drops nothing.
  • Consumers test open before a set: the sets of OPEN_LIMITS list every id the code has today, for display only.
  • limitsOf returns new sets on every call; OPEN_LIMITS and BASE_HANDS are frozen.

The ladder (ladder.ts)

// src/lib/game/ladder.ts (beside the G6 types)
import { formatShortMonthYear } from '$lib/fzp/format';
import { dayFromUtc, utcParts } from '$lib/fzp/time';
import { defaultGoal, type Goal } from '$lib/goal/goal';
import type { Day } from '$lib/timelapse/time';
import { LADDER_YEARS } from './catalogue/ladder-years';
import type { GameState, Units } from './state';

export const RUNGS: number = LADDER_YEARS.length + 1;
/** A starting value; tree-catalogue's balance script reports against it (see Decisions). */
export const RUNG_LUMP: Units = Object.freeze({ home: 2000 });

/** The last day of the UTC calendar month holding `day`. */
function endOfMonth(day: Day): Day {
  const { y, m } = utcParts(day);
  return dayFromUtc(y, m + 1, 1) - 1;
}

export function ladder(asOf: Day): Rung[] {
  const first = defaultGoal(asOf).deadline;
  const floor = endOfMonth(asOf);
  const rungs: Rung[] = [{ deadline: first, label: formatShortMonthYear(first) }];
  for (const year of LADDER_YEARS) {
    const before = rungs[rungs.length - 1].deadline;
    const deadline = Math.min(before, Math.max(floor, dayFromUtc(year, 12, 31)));
    rungs.push({ deadline, label: formatShortMonthYear(deadline) });
  }
  return rungs;
}

export function goalAt(asOf: Day, rung: number, amount?: number): Goal {
  if (!Number.isInteger(rung) || rung < 0 || rung >= RUNGS) {
    throw new RangeError(`No rung ${rung}`);
  }
  const base = defaultGoal(asOf);
  return { ...base, deadline: ladder(asOf)[rung].deadline, amount: amount ?? base.amount };
}

export function finished(s: GameState): boolean {
  return s.met.some((m) => m.rung === RUNGS - 1);
}

export function takeNext(s: GameState): GameState {
  const met = s.met.some((m) => m.rung === s.rung);
  return met && s.rung + 1 < RUNGS ? { ...s, rung: s.rung + 1 } : s;
}
  • Rung 0's deadline is defaultGoal(asOf).deadline, the last day of the window's last whole calendar month.
  • Rung k's deadline is 31 December of LADDER_YEARS[k - 1] as a Day: dayFromUtc(year, 12, 31), UTC days since 1970.
  • A rung's deadline is never later than the rung before it: a year whose 31 December falls at or after the window's end takes the rung before's deadline.
  • A rung's deadline is never before the last day of the dataset date's month, which is calendar month 0 of the view: a year already past takes that day.
  • ladder always returns RUNGS rungs, so a saved rung keeps its meaning across dataset dates.
  • A rung's label is formatShortMonthYear(deadline), such as "Dec 2061" or "Sep 2066".
  • goalAt throws RangeError for a rung outside 0 to RUNGS - 1.
  • takeNext and finished read met only; neither looks at the forecast.

/** The deadline's calendar month in the view, clamped to [0, view.lastIndex]. */
export function deadlineIndex(deadline: Day, view: TimelineView): number {
  const a = utcParts(deadline);
  const b = utcParts(view.months[0]);
  const i = (a.y - b.y) * 12 + (a.m - b.m);
  return Math.min(Math.max(i, 0), view.lastIndex);
}

export function readRun(view: TimelineView, goal: Goal): RunReading | null {
  if (view.months.length === 0 || view.filledThrough < 0) return null;
  const i = deadlineIndex(goal.deadline, view);
  if (i > view.filledThrough) return null;
  const reading = readGoal(goal, view, i);
  if (!reading) return null;
  return {
    homes: goal.measure.valueAt(view, i),
    reachedOn: reading.reachedOn,
    stages: { ...view.rows[i].inProgress },
    waitingMoney: view.waitingMoney?.[i] ?? null
  };
}

export function resultOf(
  s: GameState,
  reading: RunReading,
  take: RunTake,
  input: SideInput,
  meta: { amount: number; datasetVersion: string; at: string }
): RunResult {
  const first = reading.reachedOn !== null && !s.met.some((m) => m.rung === s.rung);
  const side = sideShown(s).flatMap((g) => {
    const r = g.read(input);
    return r !== null && r.value >= r.target ? [{ id: g.id, reward: { ...g.reward } }] : [];
  });
  return {
    rung: s.rung,
    amount: meta.amount,
    datasetVersion: meta.datasetVersion,
    at: meta.at,
    homes: reading.homes,
    reachedOn: reading.reachedOn,
    stages: { ...reading.stages },
    waitingMoney: reading.waitingMoney,
    dropped: { ...take.dropped },
    collected: { ...take.collected },
    lump: first ? { ...RUNG_LUMP } : null,
    side
  };
}

export function settle(s: GameState, r: RunResult): GameState {
  const newRung = r.reachedOn !== null && !s.met.some((m) => m.rung === r.rung);
  let units = credit(s.units, r.collected);
  if (r.lump !== null && newRung) units = credit(units, r.lump);
  const side = { ...s.side };
  for (const e of r.side) {
    if (Object.hasOwn(side, e.id)) continue;
    units = credit(units, e.reward);
    side[e.id] = r.at;
  }
  const met = newRung
    ? [
        ...s.met,
        { rung: r.rung, reachedOn: r.reachedOn as Day, datasetVersion: r.datasetVersion, at: r.at }
      ].sort((a, b) => a.rung - b.rung)
    : s.met;
  return { ...s, units, met, side, runs: s.runs + 1, last: r };
}

// src/lib/game/side-goals.ts (beside the G6 types)
import type { TimelineView } from '$lib/sim/world/score/types';
import type { GameState } from './state';
import { total } from './units';

type Read = SideGoal['read'];

const inView = (v: TimelineView, i: number): boolean =>
  Number.isInteger(i) && i >= 0 && i <= v.filledThrough;

/** The plan less current law, 0 with nothing in force (compare 'preFzp'). */
const effect =
  (field: 'completedNetNew' | 'entitledNew', target: number): Read =>
  ({ view, index }) => {
    if (!inView(view, index)) return null;
    const row = view.planEffect[index];
    if (row === undefined) return null;
    return { value: view.compare === 'preFzp' ? 0 : row[field], target };
  };

/** floor(100 × collected / dropped). */
const share =
  (target: number): Read =>
  ({ take }) => {
    const dropped = total(take.dropped);
    if (dropped === 0) return null;
    return { value: Math.floor((100 * total(take.collected)) / dropped), target };
  };

const collected =
  (target: number): Read =>
  ({ take }) => ({ value: total(take.collected), target });

/** Grants paid from pools the player added (ids begin 'u-'), whole millions. */
const newMoney =
  (millions: number): Read =>
  ({ view, index }) => {
    if (view.money === null || !inView(view, index)) return null;
    let spent = 0;
    for (const p of view.money.pools) if (p.id.startsWith('u-')) spent += p.spent[index] ?? 0;
    return { value: Math.floor(spent / 1_000_000), target: millions };
  };

const funded =
  (target: number): Read =>
  ({ view, index }) => {
    if (view.money === null || !inView(view, index)) return null;
    const v = view.money.fundedHomes[index];
    return v === undefined ? null : { value: v, target };
  };

const building =
  (target: number): Read =>
  ({ view, index }) => {
    if (!inView(view, index)) return null;
    const row = view.rows[index];
    return row === undefined ? null : { value: row.inProgress.construction, target };
  };

/** Very low, low, moderate and unrecorded: the Activity panel's "Affordable". */
const affordable =
  (target: number): Read =>

  • Ids are unique and stable: a saved game keys side by them.
  • A ring at or past RUNGS is never open; such a goal is never shown.
  • Three targets are marked "to measure": funded homes, homes in construction and affordable homes have a value under current law that the code does not record. /** 'Today', 'Yesterday', '4 Mar' or '4 Mar 2025', by local calendar date. Unchanged. */
export function playedText(savedAt: string, now: Date): string {
  const d = new Date(savedAt);
  const same = (a: Date, b: Date) =>
    a.getFullYear() === b.getFullYear() &&
    a.getMonth() === b.getMonth() &&
    a.getDate() === b.getDate();
  if (same(d, now)) return 'Today';
  if (same(d, new Date(now.getFullYear(), now.getMonth(), now.getDate() - 1))) return 'Yesterday';
  const day = `${d.getDate()} ${SHORT_MONTHS[d.getMonth()]}`;
  return d.getFullYear() === now.getFullYear() ? day : `${day} ${d.getFullYear()}`;
}

Decisions

  • NEW_GAME is frozen. It is shared by every new game; a nested write would leak into the next one.
  • Malformed saves are refused whole; only drift is repaired. Today's parser refuses whole; drift (nodes, side goals, rungs removed by a catalogue or ladder change) comes from our own data changes and must not cost a player their game.
  • A rung past the ladder is lowered to the last. LADDER_YEARS is set by a measurement after games exist on staging.
  • The phase must agree with the rest. 'runs' needs a first win (the server makes the account from it, D7) and 'opening' has no runs; a save breaking either cannot come from the store.
  • Starting limits are 1 band, 4 stories, 402 m. 4 is the lowest band of the editor's default rule and 402 m its step and inner distance, as the brief asks.
  • Grants are held to the editor's bounds (3 bands, 80 stories, 3219 m), so no limit allows what the editor cannot make.
  • The ending adds observed to the presets. G4's permitting rule needs the preset bought, and "Custom timing" is a policy with preset observed; without this, call 4's custom timing could never run.
  • within ignores on, as playable does today: the switch is the document's (P12).
  • A transit rule needs a stop type bought even with an empty stop list, so nothing zoning runs before the zoning branch opens.
  • A wrong selector for the kind is outside the limits. The parser forbids it; refusing it costs nothing and keeps within total.
  • OPEN_LIMITS lists every id (FUNDING_PRESET_IDS), so a consumer that forgets to test open still shows every measure.
  • Deadlines are clamped into the window. A rung is never later than the rung before and never before the dataset date's month, so ladder always has RUNGS rungs and readRun always reads a month inside the view.
  • deadlineIndex is exported so the page gives side goals the month readRun reads.
  • settle pays the lump and a side reward only with the record it makes. A result settled twice, by a double click or a replayed write, cannot pay twice.
  • RUNG_LUMP is { home: 2000 } and the side rewards run from 300 to 1,500. Starting values; the balance script of tree-catalogue reports pacing against them.
  • Side goals with no current-law baseline in the code get a measured target. Funded, building and affordable homes are non-zero under current law; the balance script measures them and the rule in Side goals raises a target that current law already meets.
  • Policy goals read 0 with nothing in force, because the view's comparison is then the old zoning and its effect is not the player's.
  • Public money per added home is not a side goal. Lower is better, and SideGoal.read is met from below.
  • The tally's stage rows use the map key's four groups and labels, so the player meets one set of stage names.
  • The currency is called "units", as the design names it, with "unit" for one.
  • words.spec.ts is written here. The write set names words.ts without a spec; the words need their exact strings tested.
