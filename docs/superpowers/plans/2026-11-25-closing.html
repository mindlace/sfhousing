Closing implementation plan

Implements the closing unit of the incremental loop: the journeys, the existing e2e specs made true, the reach check, the run bench and the documents.

For agentic workers REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps are checklist items; progress is kept in the workspace ledger, not in the plan.

Overview

Goal
Prove the merged incremental loop end to end in e2e, rename and widen the dataset reach check, add the run bench, and make every current document and test true to one address, no levels, no Remix and the name "SF Housing".
Architecture
The unit writes tests, two scripts and documents only; it changes nothing under src/ or pipeline/. It runs on the integration branch after every other unit (rows G1 to G8, E1, E2, M1, R1, U1 and T1) has merged, so every selector, word and helper named here is checked against the merged code first, and the code wins. New e2e helpers live in e2e/helpers/play.ts; the reach check reuses tree-catalogue's engine runner. The plan will be checked for independent lanes (task groups sharing no dependency edge and no file); the closing note lists the groups this plan has.
Tech Stack
Playwright (projects chromium and mobile, playwright.config.ts; the headed bench playwright.bench.config.ts), Vitest server project (vite.config.ts:54-62, scripts/**/*.spec.ts), tsx for scripts, Markdown docs.
Spec

  • Signoff fails on server stderr, on timing crutches and on retried flakes. Timing is measured only on a quiet machine.
