Overview

Goal
A policy goal (policy-homes-1 to -3, approved-homes) reads planEffect while SideInput.inForce is true and 0 while it is false, whatever view.compare holds; tree-balance passes inForce; tuning.ts is tuned until tree-balance exits 0 on the production dataset.
