**Goal:** Scaffold the sfhousing repo (SvelteKit 2 + Svelte 5 + Tailwind 4 on Cloudflare Workers) with D1/Drizzle migration tooling, the immutable range-capable `/data/<datasetVersion>/*` R2 route, app shell with `/about` and `/attribution`, Vitest client+server projects, a Playwright+axe e2e harness, CI/CD and docs, so wave-2 subsystems can branch from it.

## Global Constraints

Verbatim from spec §3:

- **Free and open source.** No paid APIs and no vendor keys are needed to run or build it. Licence: MIT for code (OD-3). Data attribution is shown in-app (ODbL for the OSM/Protomaps basemap and Overture, PDDL/public domain for DataSF).
- **Determinism.** The same `Plan` + `datasetVersion` gives the same buildings and the same score, on every machine.
- **Overshoot is meaningful.** No readout caps at 100% of a target.
- **Honesty of numbers.** Every unit count is labelled with what it is (M1: *theoretical max buildout*). Net counts are shown, not gross. Sources and vintages are visible.
- **Performance targets.** Existing-city view pans at 60 fps on a 2022-era laptop. Generated buildings appear within 150 ms of pointer-up for strokes covering ≤ 500 parcels. A whole-city repaint (≈150k parcels) finishes within 5 s, off the main thread. The first meaningful paint transfers ≤ 5 MB (parcel chunks load lazily under the brush).
- **Mobile works.** Touch painting uses an explicit mode switch. Layout works at 375 px.
- **Data is static and versioned.** The worker does no geo computation at runtime.
- **Cross-project conventions apply:** Conventional Commits, worktrees for all work, bare-name Cloudflare resources (`sfhousing`), and the migration workflow via Drizzle.

Interface rows (verbatim, spec §2):

- **I12** Data manifest: `/data/<datasetVersion>/manifest.json` → `{ datasetVersion, builtAt, sources: { id, label?, url, retrievedAt, license }[], chunks: { cellId, bbox, url, parcelCount }[], buildingsTiles: url, basemapTiles: url, glyphs: url /* MapLibre {fontstack}/{range}.pbf template */, sprite?: url, neighborhoods: url }`. All `url`s are root-relative (`/data/<v>/…`). Every eligible-or-not parcel appears in exactly one chunk. … Published versions are immutable and retained indefinitely. `datasetVersion` matches `^(\d{4}-\d{2}-\d{2}-[0-9a-f]{8}|fixture-\d+)$` everywhere it is validated. - **I16** The worker var `PUBLIC_DATASET_VERSION` names the current version for new plans. map-view and the worker host take the manifest as a parameter, never a global. Platform passes the version as data, never as a client global.

## Review Focus

1. **Range edge forms** — `bytes=-N` with N > size, `bytes=a-b` with b ≥ size, `bytes=-0`: expect 206 clipped to the object, 206 clipped, and 416 respectively; never a wrong `Content-Range` or a 500. Pinned in Task 3 (fake) and Task 7 (real workerd: suffix range and 416).
2. **Encoded traversal reaching the route** — SvelteKit hands `[...path]` already percent-decoded, so `/data/fixture-0/a%2F..%2Fb` arrives as `a/../b`: expect 404 `no-store` and zero R2 calls. Pinned in Task 3.
3. **Conditional + range together** — `Range` plus a matching `If-None-Match`: expect 304 (not 206), with ETag and immutable cache headers. Pinned in Task 3.
4. **HEAD on a missing object or bad path** — expect 404 with `max-age=60` (missing) or `no-store` (bad path), never 500/503. Pinned in Task 3.
5. **Malformed manifest on `/attribution`** — invalid JSON or a manifest failing schema: expect a 200 page with "Source list unavailable for this dataset version." and all fixed notices. Pinned in Task 6.

`src/lib/data/manifest.ts`:
```ts
import { z } from 'zod';

/** I12 datasetVersion pattern. The single definition; everything else re-exports it. */
export const DATASET_VERSION_RE = /^(\d{4}-\d{2}-\d{2}-[0-9a-f]{8}|fixture-\d+)$/;

const DatasetVersion = z.string().regex(DATASET_VERSION_RE);
const RootRelativeUrl = z.string().startsWith('/data/');

export const ManifestSourceSchema = z.object({
  id: z.string().min(1),
  label: z.string().optional(),
  url: z.string().url(),
  retrievedAt: z.string(),
  license: z.string()
});

export const ManifestSchema = z.object({
  datasetVersion: DatasetVersion,
  builtAt: z.string(),
  sources: z.array(ManifestSourceSchema),
  chunks: z.array(
    z.object({
      cellId: z.string(),
      bbox: z.tuple([z.number(), z.number(), z.number(), z.number()]),
      url: RootRelativeUrl,
      parcelCount: z.number().int().nonnegative()
    })
  ),
  buildingsTiles: RootRelativeUrl,
  basemapTiles: RootRelativeUrl,
  glyphs: RootRelativeUrl,
  sprite: RootRelativeUrl.optional(),
  neighborhoods: RootRelativeUrl
});
export type Manifest = z.infer<typeof ManifestSchema>;

/** The subset /attribution needs; tolerant of the rest of the manifest. */
export const ManifestSourcesSchema = ManifestSchema.pick({
  datasetVersion: true,
  builtAt: true,
  sources: true
});
export type ManifestSources = z.infer<typeof ManifestSourcesSchema>;

export function manifestUrl(version: string): string {
  return `/data/${version}/manifest.json`;
}
```
(I12 does not fix `cellId`'s or `bbox`'s exact types; `string` and a 4-number tuple are this plan's reading — keep them, data-pipeline may tighten.)

```ts
// In-memory R2Bucket subset: get (range/onlyIf as Headers), head, put. Mirrors the
// workers R2 API shape the /data route depends on; not a general R2 emulator.
type Stored = { bytes: Uint8Array; etag: string; uploaded: Date; contentType?: string };

export type FakeRange = { offset: number; length?: number } | { suffix: number };

export class FakeR2Bucket {
  calls: { method: 'get' | 'head'; key: string }[] = [];
  private objects = new Map<string, Stored>();
  private n = 0;

  put(key: string, body: Uint8Array | string, opts: { contentType?: string } = {}): void {
    const bytes = typeof body === 'string' ? new TextEncoder().encode(body) : body;
    this.objects.set(key, {
      bytes,
      etag: `etag${++this.n}`,
      uploaded: new Date('2026-10-10T00:00:00Z'),
      contentType: opts.contentType
    });
  }

  private meta(key: string, s: Stored, range?: FakeRange) {
    return {
      key,
      size: s.bytes.length,
      etag: s.etag,
      httpEtag: `"${s.etag}"`,
      uploaded: s.uploaded,
      httpMetadata: { contentType: s.contentType },
      range,
      writeHttpMetadata(h: Headers) {
        if (s.contentType) h.set('content-type', s.contentType);
      }
    };
  }

  async head(key: string) {
    this.calls.push({ method: 'head', key });
    const s = this.objects.get(key);
    return s ? this.meta(key, s) : null;
  }

  async get(key: string, opts: { range?: Headers; onlyIf?: Headers } = {}) {
    this.calls.push({ method: 'get', key });
    const s = this.objects.get(key);
    if (!s) return null;
    const inm = opts.onlyIf?.get('if-none-match');
    const im = opts.onlyIf?.get('if-match');
    const etagMatches = (v: string) =>
      v.trim() === '*' || v.split(',').some((t) => t.trim().replace(/^W\//, '') === `"${s.etag}"`);
    if ((inm && etagMatches(inm)) || (im && !etagMatches(im))) return this.meta(key, s); // no body
    const range = parseRange(opts.range?.get('range') ?? null, s.bytes.length);
    let slice = s.bytes;
    if (range) {
      const { start, end } = resolve(range, s.bytes.length);
      slice = s.bytes.slice(start, end + 1);
    }
    return {
      ...this.meta(key, s, range ?? undefined),
      body: new Blob([slice]).stream(),
      arrayBuffer: async () => slice.slice().buffer
    };
  }
}

function parseRange(h: string | null, size: number): FakeRange | null {
  if (!h) return null;
  const m = /^bytes=(\d*)-(\d*)$/.exec(h.trim());
  if (!m || (m[1] === '' && m[2] === '')) throw new Error('invalid range');
  if (m[1] === '') {
    const suffix = Number(m[2]);
    if (suffix === 0) throw new Error('unsatisfiable range');
    return { suffix };
  }
  const offset = Number(m[1]);
  if (offset >= size) throw new Error('unsatisfiable range'); // R2 throws here (spec §4.4.6, I)
  return m[2] === '' ? { offset } : { offset, length: Number(m[2]) - offset + 1 };
}

function resolve(r: FakeRange, size: number) {
  if ('suffix' in r) return { start: Math.max(0, size - r.suffix), end: size - 1 };
  const end = r.length === undefined ? size - 1 : Math.min(size, r.offset + r.length) - 1;
  return { start: r.offset, end };
}
```

```ts
import type { RequestHandler } from './$types';
import { dataKey } from '$lib/server/data/key';

const IMMUTABLE = 'public, max-age=31536000, immutable';
const CONTENT_TYPES: Record<string, string> = {
  json: 'application/json',
  geojson: 'application/geo+json',
  pmtiles: 'application/vnd.pmtiles',
  pbf: 'application/octet-stream',
  bin: 'application/octet-stream'
};
const CORS = {
  'access-control-allow-origin': '*',
  'access-control-expose-headers': 'Content-Range, Content-Length, ETag, Accept-Ranges'
};

type R2Range = { offset?: number; length?: number } | { suffix: number };

function text(status: number, body: string, cache: string): Response {
  return new Response(body, {
    status,
    headers: { 'content-type': 'text/plain; charset=utf-8', 'cache-control': cache, ...CORS }
  });
}

function resolveKey(params: { version: string; path: string }) {
  return dataKey(params.version, params.path);
}

function objectHeaders(obj: R2Object, path: string): Headers {
  const h = new Headers(CORS);
  obj.writeHttpMetadata(h);
  const ext = path.slice(path.lastIndexOf('.') + 1).toLowerCase();
  h.set(
    'content-type',
    CONTENT_TYPES[ext] ?? obj.httpMetadata?.contentType ?? 'application/octet-stream'
  );
  h.set('etag', obj.httpEtag);
  h.set('accept-ranges', 'bytes');
  h.set('last-modified', obj.uploaded.toUTCString());
  h.set('cache-control', IMMUTABLE);
  h.set('x-content-type-options', 'nosniff');
  return h;
}

/** Inclusive byte span R2 actually returned, clipped to the object. Null if empty. */
function span(r: R2Range, size: number): { start: number; end: number } | null {
  let start: number, end: number;
  if ('suffix' in r) {
    start = Math.max(0, size - r.suffix);
    end = size - 1;
  } else {
    start = r.offset ?? 0;
    end = r.length === undefined ? size - 1 : Math.min(size, start + r.length) - 1;
  }
  return end >= start ? { start, end } : null;
}

export const GET: RequestHandler = async ({ params, request, platform }) => {
  const key = resolveKey(params);
  if (!key) return text(404, 'Not found', 'no-store');
  const bucket = platform?.env?.BUCKET;
  if (!bucket) return text(503, 'Data storage unavailable', 'no-store');

  const rangeHeader = request.headers.get('range');
  const rangeHeaders = new Headers(request.headers);
  if (rangeHeader?.includes(',')) rangeHeaders.delete('range'); // multi-range → full 200
  const singleRange = rangeHeaders.has('range');

  let obj: R2Object | R2ObjectBody | null;
  try {
    obj = await bucket.get(key, { range: rangeHeaders, onlyIf: request.headers });
  } catch (err) {
    if (!singleRange) throw err;
    const meta = await bucket.head(key);
    if (!meta) return text(404, 'Not found', 'public, max-age=60');
    return unsatisfiable(meta.size);
  }
  if (!obj) return text(404, 'Not found', 'public, max-age=60');

  const headers = objectHeaders(obj, params.path);
  if (!('body' in obj)) {
    return new Response(null, {
      status: request.headers.has('if-none-match') ? 304 : 412,
      headers
    });
  }
  if (singleRange && obj.range) {
    const s = span(obj.range as R2Range, obj.size);
    if (!s) return unsatisfiable(obj.size);
    headers.set('content-range', `bytes ${s.start}-${s.end}/${obj.size}`);
    headers.set('content-length', String(s.end - s.start + 1));
    return new Response(obj.body, { status: 206, headers });
  }
  headers.set('content-length', String(obj.size));
  return new Response(obj.body, { status: 200, headers });
};

function unsatisfiable(size: number): Response {
  return new Response(null, {
    status: 416,
    headers: { 'content-range': `bytes */${size}`, 'cache-control': 'no-store', ...CORS }
  });
}

export const HEAD: RequestHandler = async ({ params, platform }) => {
  const key = resolveKey(params);
  if (!key) return text(404, 'Not found', 'no-store');
  const bucket = platform?.env?.BUCKET;
  if (!bucket) return text(503, 'Data storage unavailable', 'no-store');
  const obj = await bucket.head(key);
  if (!obj) return text(404, 'Not found', 'public, max-age=60');
  const headers = objectHeaders(obj, params.path);
  headers.set('content-length', String(obj.size));
  return new Response(null, { status: 200, headers });
};

export const OPTIONS: RequestHandler = async () =>
  new Response(null, {
    status: 204,
    headers: {
      'access-control-allow-origin': '*',
      'access-control-allow-methods': 'GET, HEAD, OPTIONS',
      'access-control-allow-headers': 'Range, If-None-Match, If-Match',
      'access-control-max-age': '86400'
    }
  });
```
