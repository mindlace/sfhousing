Overview

  • Goal: while the run view is on, the timeline controller draws every cell's parts as one solid layer and one ghost layer. That is about 6 deck draws a frame in place of about 500, and the picture is unchanged.
  • Architecture: TimelineController.setMerged(on) joins the installed cells' packs and encoded attributes, in cell-id order, into one merged pack. emit then sends timeline-solid-run and timeline-ghost-run, built by the same makeLayer props as a per-cell layer. The join is rebuilt only when a cell's layers were rebuilt or removed while merged, never on setTime. SimMap.setRunView switches it.
  • Tech stack: TypeScript, deck.gl SolidPolygonLayer with binary attributes, Svelte 5, Vitest (server and browser projects), and the Playwright bench.
  • Spec: the map-run spec, in the package worktree at /Users/mindlace/Projects/sfhousing/.claude/worktrees/incremental-feel/.claude/worktrees/incremental-loop/docs/superpowers/specs/2026-11-24-map-run-design.html. Sections: §sec-design-merged, §sec-design-visible, §sec-tests-merged, §sec-tests-component (last item), §sec-files, §sec-decisions. Also closing 2026-11-24-closing-design.html §sec-design-bench.
  • Evidence: .superpowers/sdd/2026-11-25-run-frame/trace-1.md. In the experiment that left out the cell layers while locked, the case passed at p95 9.9 ms.

Task 1: setMerged and the merged layers in the timeline controller

  • Modify: src/lib/map/timeline-controller.ts (makeLayer 720-740, emit 746-763, the install, remove and re-encode paths near 560-600).

  • Produces: TimelineController.setMerged(on: boolean): void, public, doc comment "One merged solid and ghost layer over every cell while on; per-cell layers while off." Layer ids are timeline-solid-run and timeline-ghost-run.
  1. Write the failing tests in a describe('setMerged') block. Each one is one bullet of §sec-tests-merged, plus the Review Focus tests:
    • "emits one merged pair": with cells A and B installed (both with parts), setMerged(true) makes the last setLayers ids equal ['timeline-solid-run', 'timeline-ghost-run', 'timeline-bars'?, 'timeline-halos'?, ...overlay ids], the same tail as unmerged, and no id matches TIMELINE_PART_LAYER.
    • "join layout": the merged data.length is the sum of the cells' partCount. attributes.getPolygon.value is A's positions then B's. startIndices is A's then B's offset by A's vertex count (positions length / 2). getElevation, getFillColor and getTlA/getTlB/getTlC at merged index A.partCount + i equal B's per-cell accessor at i.
    • "same props": every prop of a merged layer except id, data, the accessor functions and updateTriggers.getTlC deep-equals the matching per-cell layer's. That includes extruded, _normalize, _windingOrder, elevationScale, extensions (the same extension instance), timelapsePass, pickable, autoHighlight/highlightColor on the solid, parameters on the ghost, and beforeId.
    • "unmerge": setMerged(false) emits layers whose ids and props equal those of a controller given the same updates and never merged.
    • "apply while merged": an applyTimeline that changes B, run through its slices, gives a new merged data object holding B's new parts. "setTime while merged": setTime leaves the merged data object identical (toBe) and calls setLayers no more times than unmerged does.
    • "update then unmerge": B updated while merged, then setMerged(false), gives B's per-cell layers with the updated pack.
    • "idempotent": a second setMerged(true) calls setLayers 0 more times, and so does setMerged(false) on a fresh controller.
    • "re-encode while merged": setLookups with new lookups, its slices run, changes the merged getTlC values to the re-encoded ones.
    • "theme while merged": setTheme to the other theme gives merged fill colours of that theme.
    • "remove while merged": B removed leaves a join of A only. "no parts": every cell with partCount 0 emits no merged layer.
