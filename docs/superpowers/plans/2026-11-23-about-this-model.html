Overview

Goal
"About this model" is the one place for background: what the numbers mean, the assumptions with their sources and the published estimates beside them, the data and licences with every credit, and how to use the app (keyboard shortcuts, published plans). It is the page /about on every route; on /sim and /s/<id> every link to it opens the same content as a dialog over the map, so the run, the playhead and the live assumptions stay. /attribution redirects into it. The map's credit is MapLibre's collapsed (i) at every width, holding a linked "© OpenStreetMap" and an "About this model" link, shown for five seconds on load, one line high, clear of Reset view and the painting strip. /sim's header loses Shortcuts; Space plays and pauses. Details and Paint's Details end in one "How this is worked out" link; the dataset version, the market paragraph and the source citations that say "RHNA" live only in About.
Architecture
Page and shell work, no engine change. A new folder src/lib/about/ holds the parts (AboutMeanings, AboutAssumptions, AboutData, AboutUsing), their strings (copy.ts), the credits (credits.ts), the link rule (links.ts) and the dialog (AboutDialog.svelte, which replaces src/lib/fzp/SourcesDialog.svelte). The Sources dialog's body becomes src/lib/fzp/ProvenanceBody.svelte, shown live in the dialog and model-wide on the page (modelSections, src/lib/fzp/provenance.ts). The parts take their colours from two custom properties the container sets, because the page is light at every setting and the dialog follows the theme. On the map side: creditHtml() replaces attributionHtml, SimMap gains a creditShowMs prop and SimMapHandle.collapseCredit(). No hashed file, CSP, shader or layer changes; no dataset upload.
Tech Stack
SvelteKit 2, Svelte 5 runes, TypeScript, Tailwind 4, MapLibre GL JS 6.13 (AttributionControl with compact, the locale map option), Vitest (server project for *.spec.ts, client project for *.svelte.spec.ts), Playwright, axe through expectNoA11yViolations.
