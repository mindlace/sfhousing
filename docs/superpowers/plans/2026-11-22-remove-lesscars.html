Remove less cars implementation plan

Implements the remove-lesscars build unit: delete /fzp, /lesscars and everything only they use, keep the freeway-land catalog, and deliver interface row L1.

For agentic workers REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps are checklist items; progress is kept in the workspace ledger, not in the plan.

Overview

Goal
The app, worker, map, manifest and pipeline carry no less cars; the freeway-land catalog moves to pipeline/enrichment/freeway-land.json and decides eligibility exactly as before; PATHS is held to the pipeline's imports by a test; the fixture is regenerated (L1).
Architecture
One serial lane of seven tasks. Deletions go leaf-first: the app and worker (nothing else imports them), then the pipeline's less-cars steps (the only readers of scenarios.lesscars at build time), then the manifest schema and the map style, then the catalog move, then PATHS, then the regenerated fixture that proves L1, then the docs. The spec is exhaustive; each step names the spec section it implements and adds only what the spec leaves open.
Tech Stack
SvelteKit 2, Svelte 5, TypeScript, Zod 4, MapLibre style JSON, Node pipeline (DuckDB, tippecanoe, pmtiles), Vitest (projects server, client, pipeline), Playwright, chreode.

Builder's call: task order The suggested cut put the manifest schema and the catalog move before the pipeline removal. The code argues otherwise. pipeline/steps/manifest.ts:64 returns parseManifest({... lesscars ...}) and pipeline/steps/check-lesscars.ts:104 reads parseManifest(...).scenarios?.lesscars, so the schema change breaks the build until the less-cars step and V35 are gone. And 13 of the 22 files that import the catalog's path or module are files the removal deletes (pipeline/steps/lesscars*.ts, pipeline/test/lesscars-*.ts), so moving the catalog first would mean editing files that are about to be deleted. The order is therefore: app, pipeline removal, manifest and map, catalog move, PATHS, fixture, docs.
