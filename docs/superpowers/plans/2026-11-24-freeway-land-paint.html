Freeway land in Paint implementation plan

Freeway-land catalog lots are written to the chunks as ineligible, so Paint cannot build on them.

For agentic workers REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps are checklist items; progress is kept in the workspace ledger, not in the plan.

Overview

  • Goal. Every freeway-land catalog lot's chunk record has eligible=false, so Paint (src/lib/plan/resolve.ts applyOp, which checks only rec.eligible) never paints it.
  • Architecture. The change is made where the chunks are encoded (writeChunks, pipeline/steps/chunks.ts), not in 60_attributes.sql. parcel_out.eligible and readParcelRecords stay as they are, because the scenario step's T13 calibration panel and the scenario.freeway_land.net_removed counts read them and must not change (calibration describes the past market, docs/dev/pipeline.md "Freeway land"). No client code changes.
  • Tech stack. TypeScript pipeline (tsx, DuckDB), Vitest pipeline project.
  • Spec. docs/superpowers/specs/2026-11-24-freeway-land-paint-design.html

Global constraints

  • The chunk format (src/lib/data/parcel-chunk.ts) does not change: no new column.
  • The road-like rule, road-lots.json and freeway-land.json do not change.
  • The fixture's scenarios/fzp/calibration.json and parcels.bin (decoded) are identical before and after; only chunk files and what hashes them change.
  • Every test calls expect. Conventional Commits, no Claude attribution.
  • Port 4173 may be in use by another session: never kill it, wait.

Review focus

  • The re-encode check in build.ts (the second writeChunks call into reencode) gets the same catalog set; otherwise the byte comparison fails on every catalog lot.
  • A standalone check <v> on an older out dir: the new V17 clause fails it, the same way V17 already does for a newer catalog. Acceptable; note it in the docs.
  • A catalog id with no parcel_out row is ignored by writeChunks (the scenario step already warns about it).
  • Paint's Level 1 room drops by the static capacity on freeway land (~32.8k homes live); the goal must stay reachable (Task 2).
