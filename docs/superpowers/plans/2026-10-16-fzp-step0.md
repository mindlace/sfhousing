# FZP timelapse step 0 (shared types and time) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the design's Dependency-order step 0: the shared time module, deterministic math, the shared timelapse/sim/map/codec type declarations and signature stubs, so every step-1+ subsystem compiles against them.

**Architecture:** Pure, worker-safe TypeScript modules. `src/lib/timelapse/` (time, math, types, model stubs, projects) and `src/lib/data/scenario-codec.ts` are imported by the data pipeline by relative path, so they use **relative imports only** (no `$lib`). Type declarations copy the design's Interface-table rows verbatim; each row gets a compile-time equality assertion (checked by `npm run check`) against a literal restatement of the row.

**Tech Stack:** TypeScript (strict), Vitest server + client (Playwright Chromium) projects, ESLint flat config, C fdlibm 5.3 (netlib) for the golden reference.

**Spec:** Design `docs/superpowers/design/2026-10-16-1903-fzp-timelapse.md` (Interface table T1–T12, Dependency order step 0, reconciliation rounds 2–4). Step-0 sections: stage-calibration spec §1 "Step 0", §2 internal exports, §4.1, §4.1a, §6 (`time.test.ts`, `math.golden.test.ts`); project-records spec §1 "In", §4.9 "Delivery order", V20 (§4.9 invariants table); scenario-data spec §2 "Internal types" (the step-0 code block); timelapse-sim spec §1 `types.ts` row, §2 "Internal types" code block, §6 `types.spec.ts`, AC-14; timelapse-render spec §1 "Step 0".

## Global Constraints

- Scope is strictly step 0: declarations, stubs, and the bodies the specs place in step 0 (`time.ts`, `math.ts`, the T2 constants and `pathwayStages`, the `projects.ts` validator, `fillStories`). No step-1+ body.
- T-row type text must match the design rows exactly. If a row cannot be expressed as written in TypeScript, stop and escalate (do not adjust it).
- `model.ts` stubs: every T12 export with its exact T12 signature, each body `throw new Error('not implemented')`. `model.ts` imports nothing outside `src/lib/timelapse` (AC-7).
- Scenario-codec step 0: "the constants, `LandUseClass`, `ScenarioParcels`, `ScenarioFormatError`, and the function signatures throwing `'not implemented'`."
- `Math.exp` and `Math.log` (and `Math.pow`, `Math.log1p`, `Math.expm1`) never appear on a determinism path; an ESLint `no-restricted-properties` rule scoped to `src/lib/timelapse/**` and `pipeline/lib/fzp-cal/**` bans those `Math` members.
- `math.ts`: "line-for-line TypeScript ports of fdlibm 5.3"; words read/written through one module-level `DataView` over an 8-byte `ArrayBuffer`; only IEEE-754 `+ − × ÷` and integer bit ops; fdlibm's Sun notice kept in the header.
- The editor is unchanged: `src/lib/sim/host.ts`, `display.ts`, `client.ts` get no diff; `SimRequest` and `SimResponse` stay byte-identical in `protocol.ts`.
- Worker-safe: no zod, no DOM, no `$app` in `src/lib/timelapse/**`, `src/lib/sim/scenario/**`, `scenario-codec.ts`.
- Code style: 2-space indent, single quotes, no trailing commas, 100 columns. Conventional Commits. Vitest runs with `expect.requireAssertions`: every test calls `expect`.
- Gate per task: `npm run check`, `npm run lint`, and the task's tests pass. Final gate: `npm run check && npm run lint && npm run test:unit`.

## Review Focus

1. `math.ts` on special inputs (±0, subnormals, ±Infinity, NaN, the exact overflow/underflow thresholds and their neighbours): bit-exact with C fdlibm; NaN compared with `Number.isNaN`, not bits (engines may canonicalise NaN payloads). Task 2.
2. `parseProjectsFile` fed garbage (`null`, an array, a string, a project that is `null`, `history` that is an array): throws `ProjectsFormatError` naming the path, never a `TypeError`. Task 3.
3. `monthsIn` when `day < enteredDay`: plain `Math.floor` semantics (negative result), no clamp. Task 1.
4. New `SimMapHandle` methods called before the map is ready, or `timelinePick` passed to `SimMap`: no throw, no change to editor behaviour. Task 5.
5. `protocol.ts` re-export creates a type-only import cycle with `sim/scenario/types.ts`: must compile under `svelte-check` and not emit a runtime import (use `import type` / `export type *`). Task 6.

- [ ] **Step 1: Golden generator.** `generate.sh` (POSIX sh, `set -eu`): downloads `e_exp.c`, `e_log.c`, `fdlibm.h` from `https://www.netlib.org/fdlibm/` into a `mktemp -d` directory, compiles `cc -O0 -ffp-contract=off -fno-strict-aliasing -D__LITTLE_ENDIAN scripts/math-golden/driver.c <tmp>/e_exp.c <tmp>/e_log.c -I<tmp> -o <tmp>/golden`, and writes the driver's stdout to `src/lib/timelapse/fixtures/math-golden.json`. `driver.c` calls `__ieee754_exp` / `__ieee754_log` (declared in `fdlibm.h`) and prints `{ "source": "<netlib fdlibm 5.3 e_exp.c/e_log.c; cc flags; generate.sh>", "exp": [[xHex, yHex], …], "log": [[xHex, yHex], …] }`, each value a 16-hex-digit IEEE-754 bit pattern (lower-case). Inputs are built in C from bit patterns or exact literals, about 200 per function:
  - **exp:** ±0; ±min subnormal (`0x0000000000000001`); ±max subnormal; ±`DBL_MIN`; 1, −1; k·ln2 for k = −20..20 and the reduction edges 0.5·ln2, 1.5·ln2 (± one ulp); `o_threshold` 7.09782712893383973096e+02 and its next-up; `u_threshold` −7.45133219101941108420e+02 and its next-down; −708.5, −740 (subnormal result path); ±2⁻²⁸ and neighbours; the logit range −30..5 in steps of 0.25; ±Infinity; NaN; 40 values from a fixed 64-bit LCG mapped into [−745, 710].
  - **log:** ±0; min/max subnormal; `DBL_MIN`; `DBL_MAX`; 1; 1 ± 2⁻ᵏ for k = 1..52 step 3; √2/2 and √2 (± one ulp); powers of two 2⁻¹⁰⁷⁴..2¹⁰²³ step 64 in the exponent; (1 − ρ) for 40 log-spaced ρ in [1e-6, 0.5]; −1, −Infinity (NaN results); +Infinity; NaN; 40 LCG positive doubles.
  Run `sh scripts/math-golden/generate.sh` and commit the JSON. Sanity-check that the C output agrees with the platform `exp`/`log` within 1 ulp on finite inputs (print-only check inside the driver behind an env flag is fine, or a one-off; not committed as a test).
