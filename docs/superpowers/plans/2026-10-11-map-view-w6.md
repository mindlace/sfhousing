> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn map-view's deferred e2e placeholders (E2, E3, E5, E7, E8, E9, E10) into real tests now that brush-tool, scoreboard and plan-sharing have landed. Also add `npm run bench:map` + `docs/dev/map-perf.md`, fix the maplibre "Worker failed to load" console error in the client test project if it is ours, and release the WebGL probe's context.

**Architecture:** Tests drive the real app on the VITE_E2E preview build. **Tech Stack:** Playwright (projects `chromium` 1280 and `mobile` 375), SvelteKit preview on :4173 (webServer builds with `VITE_E2E=1`), Vitest browser project.

**Spec:** `docs/superpowers/specs/2026-10-10-map-view-design.md` (§6 e2e list, §4.5–§4.8, §4.12, §7 acceptance).

## Global Constraints

  - E5: Feature-state persistence: paint, zoom out to z11, zoom back in. The replaced building is still hidden after its tiles reload.
  - E7: Chunk failure (route a chunk to 500): the error outline and chip appear; Retry with success clears them.
  - E8: `reducedMotion:'reduce'` context: buildings are at full height on the first frame after the update.

## Review Focus

1. **Flaky waits.** Every assertion waits on a condition (an `idle` event, a `waitForFunction` on hook state, or `expect.poll`), never a fixed `waitForTimeout`.
2. **E5 really reloads tiles.** A zoom-out and back can be served from MapLibre's tile cache. Force a refetch (as the F9 client test does with `refreshTiles`, or check a tile-request counter) so the test proves persistence across a reload.
3. **E8's "first frame".** Assert on the first `render` after the diff applies (rising layers absent, settled `elevationScale` 1), not after an arbitrary delay.
4. **Golden determinism (E9).** Disable animations, wait for idle and worker completion, fix the viewport and device scale factor, mask nothing that hides real regressions, and commit goldens generated on this platform. Name the platform suffix in the report.
5. **E10 honesty.** If transfer bytes are not deterministic in CI, make it a measured soft check: log the value and fail only on a generous ceiling, or annotate it. Say so in the test and the report.
