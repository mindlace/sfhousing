Finite funding implementation plan

Every funding source gets a bound from evidence, the federal pool gets a yearly ceiling, and Pool.uncapped leaves the code.

For agentic workers REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps are checklist items; progress is kept in the workspace ledger, not in the plan.

Overview

Goal
Make today's public money finite: funding.json at schema 2 with a bound on every source and a federal yearly ceiling, pools whose inflows follow those bounds, and no pool anywhere that can always pay, while older datasets and documents keep loading and playing as they did.
Architecture
The pipeline (pipeline/enrichment/funding-schema.ts, pipeline/lib/fzp-cal/funding.ts) turns each bound into inflows and provenance; the calibration loader (src/lib/timelapse/model.ts) converts an older dataset's uncapped federal pool to one yearly inflow of LEGACY_UNCAPPED_DOLLARS; both engines, the score and the page then drop every read of the flag. One serial lane: the pipeline emits through src/lib/timelapse types and checkPool, so a short-lived optional Pool.uncapped? (added in Task 2, removed in Task 7) lets the emission land before the many readers go.

// pipeline/enrichment/funding-schema.ts (schema 2 of pipeline/enrichment/funding.json)
type Bound =
  | { kind: 'ends'; on: string; method: string; tier: 1 | 2 | 3; cite: Cite }
  | { kind: 'remaining'; dollars: number; method: string; tier: 1 | 2 | 3; cite: Cite }
  | { kind: 'none'; reason: string; tier: 1 | 2 | 3; cite: Cite };

interface CitySource {
  id: string;
  label: string;
  kind: 'goBond' | 'cop' | 'generalRevenue' | 'dedicatedTax';
  dollarsPerYear: number;
  debt: { rate: number; termYears: number; cite: Cite } | null;
  note: string;
  cite: Cite;
  bound: Bound;
}

interface StateSource {
  id: string;
  label: string;
  dollarsPerYear: number;
  tier: number;
  method: string;
  cite: Cite;
  bound: Bound;
}

interface FederalSource {
  id: string;
  label: string;
  /** The yearly ceiling. */
  dollarsPerYear: number;
  tier: number;
  method: string;
  cite: Cite;
  bound: Bound;
}
ends
on is an ISO date. The source's last yearly arrival is the last one on or before it.
remaining
The dollars the source has left in total, as of the citation: an authorisation not yet issued, a balance being spent down.
none
Law sets no end. reason says what was read that shows it.
  • Every City source, the state source and the federal source has a bound. A file without one is refused.
  • No bound has tier 4. An end nobody has read in a source is not written.
  • A source with ends emits one yearly inflow from the dataset date to on.
  • A source with remaining emits one-time inflows of dollarsPerYear on the dataset date and each anniversary until dollars is used, the last one being what is left.
  • A source with none emits one yearly inflow with no end.
  • A source whose ends.on is before the dataset date, or whose remaining.dollars is 0, emits a pool with no inflow, and its programme is not in the baseline.
  • The calibration's provenance text for each pool states its end, or that it has none, with the citation.
  • The "check" that compares implied homes a year with observed awards is kept and reads the first year.

// src/lib/timelapse/types.ts
export interface Pool {
  id: string;
  kind: PoolKind;
  label: string;
  inflows: Inflow[];
  /** non-null exactly for `goBond` and `cop` */
  debt: { rate: number; termYears: number } | null;
  /** dollars a pool may have committed or out per dollar received: 1 for every kind but `bank` */
  leverage: number;
}

export type Inflow =
  | { kind: 'once'; day: Day; dollars: Dollars }
  | { kind: 'yearly'; from: Day; to: Day | null; dollarsPerYear: Dollars };
  • Pool has no uncapped field. A pool can pay only from what it has received.
  • The baseline's federal pool has kind federal and one yearly inflow of the ceiling.
  • A baseline pool's inflows follow its source's bound (F1). A yearly inflow has to: null only for a bound of kind none.
  • A stored or published document whose pool carries uncapped loads with the field ignored.
  • A published plan or policy runs on its own dataset while that dataset exists, and every dataset built before this build has uncapped: true on its federal pool. The calibration loader reads such a pool as one yearly inflow of LEGACY_UNCAPPED_DOLLARS (100 billion dollars) from the dataset date with no end, and never refuses the calibration.
  • Where the yearly amount of such a pool is shown, it reads "No ceiling". So a policy published before this build plays as it did.
  • isNoCeiling(dollars) in src/lib/timelapse/model.ts is the one test for such a pool: a yearly amount at or above LEGACY_UNCAPPED_DOLLARS.
  • A scale entry on the federal pool scales its ceiling, as on any pool; 0 switches it off.
  • Inflow, Programme, Instrument, the award rule, the line and fundBundle are unchanged.

Removed: Pool.uncapped, the "no limit" text for anything but an older dataset's pool, the on/off-only editor for the federal pool, the uncapped sets passed to the money results.
